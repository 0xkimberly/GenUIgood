# Contributing to GenUIgood

Thanks for helping keep this list useful.

## What belongs here

Projects, research and writing about **generative UI**: systems where AI decides what interface to show and renders it from real, interactive components or a sandboxed page.

Good additions:
- Open-source protocols, frameworks, SDKs and starters
- Products that ship generative UI to real users
- Papers and essays that move the thinking forward

Out of scope:
- General AI chat UIs with no generated interface
- Pure code-generation tools, unless they produce UI at runtime
- Paid listings or affiliate links

## How to add something

1. Fork the repo and add one entry to the right section of `README.md`.
2. Use this format: `- [Name](link) – One plain sentence on what it does.`
3. Link to the primary source: the GitHub repo, the paper, or the original post.
4. Keep descriptions factual and in your own words. No marketing language.
5. Open a pull request with a short note on why it belongs.

One addition per pull request makes review faster.
